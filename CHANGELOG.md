# Changelog: feature and status changes per model

One entry per change, newest first. Each entry records:

- **Date:** the date of the change, as stated in the vendor's dated release note.
- **Model:** the `model_id` from `data/ai_model_releases.csv`.
- **Platform:** API, app, or both.
- **Change:** added, changed, removed, or deprecated.
- **Description:** one line.
- **Source:** the vendor's dated release note (URL and access date).

Where the announcement date and the availability date differ, both are recorded.

Empty means not yet recorded. Earlier entries are never overwritten; a correction is a new entry that refers to the one it corrects.
