# Comparative list of AI model releases

A source-checked, dated list of 224 general-purpose AI models from eight developers (Anthropic, DeepSeek, Google, Meta, Mistral, OpenAI, Qwen, xAI), 14 March 2023 to 7 October 2026. Retrieved 5 November 2026.

**File:** `data/ai_model_releases.xlsx`

Sheets: Read me, Models (filterable, alphabetical by developer then date), Counts, Compare versions, Not counted, Coverage, Fields, Sources.

Dates are first public availability from the vendor's own page; where vendor pages disagree, the Notes column gives both. Blank means not verified, never zero. Rows marked Unverified or Confidence low should be checked before citing.
